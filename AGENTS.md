# Anki project instructions

Read `CLAUDE.md` before editing decks, templates, media, or build scripts; it
contains the project invariants and workflows.

For new or replacement illustrations, follow **Matching illustrations for future
cards** in `CLAUDE.md`. It contains the reusable style prompt, existing reference
images, the stricter image-first question criteria, and the save/review/build
workflow. Historical prompts live in
`assets/card-visuals/generation-prompts.json`.
